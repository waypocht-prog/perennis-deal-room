# 🏗️ Capstone (v2) · Часть 5 — План реализации, атрибуты реального бизнеса, governance и комплаенс

**Проект:** Pérennis — **настоящий бизнес**, не учебный спринт. Поэтому сроки реалистичны:
сделки M&A закрываются за 6–12 месяцев, доверие строится годами. Мы не спешим — мы
строим институт с полным набором атрибутов.

---

## 🗺️ A. Реалистичная дорожная карта (по фазам, реальные сроки)

### Фаза 0 — Fondations (Мес 0–6) — «поставить фундамент»
- Юридическая структура (SAS), бренд Pérennis, сайт FR/EN/RU/AR, mentions légales.
- Комплаенс-каркас: политика KYC/AML, RGPD-реестр, шаблоны NDA и мандатов.
- Партнёрская сеть: первые нотариусы, avocats d'affaires, experts-comptables, банк.
- Инструменты: собрать MVP-платформу (Base44 + n8n + Claude + Pappers + OpenSanctions).
- Первые 2–3 покупателя из моей сети (СНГ/БВ) — брифы и мандаты.

### Фаза 1 — MVP buy-side (Мес 6–15) — «первая сделка»
- ИИ-агент Radar сорсит цели под конкретных покупателей.
- Полный цикл на 1–2 сделках: оценка → мэтчинг → outreach → DD → KYC → закрытие.
- Реалистично: **первая закрытая сделка — Мес 9–15** (цикл M&A длинный).
- Отладка процессов, первые кейсы/референсы.

### Фаза 2 — Двусторонняя платформа (Мес 15–30) — «эффект платформы»
- Строю sell-side базу (активный сорсинг продавцов), запускаю мэтчинг обеих сторон.
- Расширяю команду (аналитик, deal-manager, комплаенс).
- Членство в **CNCFA**, публичные кейсы, укрепление бренда.

### Фаза 3 — Масштаб + транзит-менеджмент как линия (Мес 30–48)
- Подключаю Orbis (пан-ЕС данные), профессиональный VDR.
- Формирую **сеть транзитных (interim) менеджеров** — отдельная линия дохода.
- Новые рынки/секторы, партнёрства с банками для финансирования покупателей.

> ⏱️ Ключевая идея: **большое видение — реалистичный темп.** Мы не обещаем чудо за 90 дней;
> мы показываем зрелый путь строительства настоящего M&A-института.

## 🧱 B. Атрибуты реального бизнеса (что нужно, чтобы это был институт, а не идея)

### Юридические
- **Форма:** SAS (société par actions simplifiée) — гибко для партнёров и роста; при
  масштабе — holding.
- **Мандат:** письменный **mandat de cession/recherche** — юр. основа комиссии (success fee).
- **Профессиональный статус (Франция):** консалтинг M&A/cession сам по себе **не является
  лицензируемой профессией** (в отличие от агента по недвижимости с carte T). НО:
  - если появляется удержание средств клиента / инвест-советы — проверить статусы
    **AMF / CIF / ORIAS** (юрист). На старте **не держим средства сделки** — они идут
    через нотариуса/адвоката/эскроу.
  - Вступить в **CNCFA** (Compagnie Nationale des Conseils en Fusions & Acquisitions) —
    хартия этики, знак доверия для продавцов.

### Операционные / защита
- **Страхование RC Pro** (assurance responsabilité civile professionnelle) — обязательный
  атрибут серьёзного советника.
- **RGPD:** registre des traitements, правовое основание обработки, срок хранения,
  DPO (внутренний или внешний), данные — в ЕС.
- **Банк + эскроу:** деньги сделки проходят через нотариуса/адвоката, не через Pérennis
  (снимает часть AML-риска и повышает доверие).

### Партнёрская сеть (обязательна для сопровождения A→Z)
- Нотариусы · avocats d'affaires (структурирование) · experts-comptables (аудит/DD) ·
  банки (финансирование покупателя) · кабинеты due diligence · налоговые консультанты ·
  страховщики · **сеть interim/транзит-менеджеров**.

### Финансирование запуска
- Старт: **bootstrapped** (мои средства) + возможный партнёр/бизнес-ангел.
- Масштаб: prêt / subvention Bpifrance, реинвест прибыли (модель высокомаржинальна).

## 🧑‍⚖️ C. Governance и этика (human-in-the-loop)
- **Человек в контуре:** агенты готовят, человек решает и подписывает. Никакого
  авто-контакта с продавцом или авто-одобрения покупателя.
- **Прозрачность:** внутри команды помечаем ИИ-черновики; клиенту — только выверенное.
- **Ответственность:** владелец решения по каждой сделке — основатель/deal-manager.

## 🛡️ D. Комплаенс-блок (ГЛАВНЫЙ КОЗЫРЬ перед жюри — раскрыт подробно)

Капитал из СНГ и с Ближнего Востока в бизнес ЕС = зона повышенного контроля. Мы
превращаем это из риска в **знак качества**: «работаем только с чистыми деньгами».

| Область | Что делаем |
|---|---|
| **KYC / LCB-FT** | верификация бенефициаров, происхождение средств; enhanced due diligence для чувствительных юрисдикций |
| **Санкции + PEP** | скрининг по спискам UN/OFAC/EU/UK (агент 6, OpenSanctions); при совпадении — стоп |
| **EU FDI Screening** | новый регламент ЕС (полит. согласие дек. 2025): проверяем, попадает ли сделка под гос-контроль иностранных инвестиций (критич. инфраструктура/технологии/чувствительные сектора, пороги владения) — при попадании готовим уведомление |
| **Конфиденциальность M&A** | NDA, анонимные тизеры, доступ к data room по разрешению |
| **RGPD** | правовое основание, минимизация, хранение в ЕС, права субъектов |
| **EU AI Act** | классификация риска ИИ-системы, прозрачность, надзор человека |

> 🔑 Позиция для питча: **комплаенс — не тормоз, а конкурентное преимущество.** Продавцу
> и государству мы даём гарантию чистоты сделки; покупателю — легитимный, «белый» вход
> в экономику ЕС.

## ⚠️ E. Риски и меры (реальный бизнес)

| Риск | Мера |
|---|---|
| 🚫 Санкционный/репутационный (капитал из СНГ) | строгий KYC, отказ при малейшем сомнении, документирование источника средств |
| 🏛️ Регуляторный (EU FDI, отраслевые ограничения) | ранняя проверка юристом, уведомление регулятора при необходимости |
| 🤐 Утечка/конфиденциальность | NDA, анонимизация тизеров, защищённый VDR |
| 💸 Лаг сделок / денежный поток | retainer + транзит-менеджмент сглаживают доход |
| 👻 Ошибки ИИ (оценка/данные) | grounding на официальных реестрах, проверка человеком |
| 🧍 Зависимость от основателя (связи) | институционализация: команда, процессы, бренд, CNCFA |
| 🤝 Доверие продавцов к «иностранным» деньгам | репутация, прозрачность, кейсы, страховка RC Pro |
