# 🤖 Capstone (v2) · ИИ-архитектура Pérennis (агенты + инструменты + MCP)

Это ядро проекта «AI for Business». Здесь — как устроена ИИ-система: какие агенты,
какие данные, какие доступы через **MCP** (Model Context Protocol — стандарт
подключения агентов к данным/инструментам **без vendor lock-in**; ключевой урок курса).

Идёт в Часть 3 (бенчмарк/выбор стека) и Часть 6 (прототип) досье.

---

## 🧭 Принцип: «конвейер сделки» из ИИ-агентов + человек в контуре

Каждый агент = один шаг жизненного цикла сделки (*deal cycle*). Оркестратор (**n8n**)
связывает их в конвейер. **Ни один шаг не публикуется/не отправляется клиенту без
одобрения человека (human-in-the-loop)** — это требование доверия и комплаенса.

```
[1] RADAR  →  [2] QUALIF & VALO  →  [3] MATCHING  →  [4] OUTREACH
                                                          │
[7] TRANSITION  ←  [6] COMPLIANCE  ←  [5] DUE DILIGENCE  ←┘
        (весь конвейер оркестрирует n8n, финал одобряет человек)
```

## 🧩 Семь агентов

### 1. Agent «Radar» — детекция целей (sell-side origination)
- **Задача:** непрерывно искать признаки «бизнес скоро останется без преемника».
- **Сигналы:** возраст руководителя 58+, отсутствие наследника, здоровые финансы,
  сектор, регион, отсутствие недавних инвестиций/найма преемника.
- **Инструменты/данные (MCP):** реестры компаний (Pappers, Infogreffe, BODACC, INSEE
  SIRENE), WebSearch (пресса, объявления, локальные новости), LinkedIn (осторожно, ToS).
- **Выход:** ранжированный список кандидатов со «скор преемственности».

### 2. Agent «Qualification & Valorisation» — оценка
- **Задача:** отсеять слабые цели, прикинуть стоимость.
- **Логика:** мультипликаторы EBITDA по сектору + упрощённый DCF; флаги «зелёный/красный».
- **Данные (MCP):** финансовая отчётность (Pappers/Infogreffe/Orbis), отраслевые мультипликаторы.
- **Выход:** карточка цели: диапазон оценки, риски, «инвест-тезис».

### 3. Agent «Matching acheteur–vendeur» — сведение сторон
- **Задача:** сопоставить профиль покупателя (сектор, бюджет, гео, риск-аппетит) с целями.
- **Данные (MCP):** CRM покупателей (HubSpot/Airtable), карточки целей из агента 2.
- **Выход:** short-list «эта цель ↔ этот покупатель», с обоснованием совпадения.

### 4. Agent «Communication multilingue & Outreach» — «мост языков»
- **Задача:** персональные письма продавцам (FR, деликатно — тема чувствительная) и
  покупателям (RU / AR / EN), в правильном тоне и с учётом культуры.
- **Данные (MCP):** Gmail/Outlook, шаблоны, CRM; движок — Claude (тон, многоязычность).
- **Выход:** черновики писем/тизеров (anonymisés) → человек проверяет и отправляет.

### 5. Agent «Due Diligence & Data Room»
- **Задача:** собрать чек-лист DD, суммировать документы, выявить юр./фин./налоговые риски.
- **Данные (MCP):** защищённая data room (Google Drive/Notion/dedicated VDR), документы сделки.
- **Выход:** сводка рисков + список «красных флагов» + вопросы к продавцу.

### 6. Agent «Conformité KYC/AML & Sanctions» ⚠️ КРИТИЧЕСКИ ВАЖЕН
- **Задача:** проверить покупателя и происхождение средств; закрыть регуляторный риск.
- **Проверки:** KYC (бенефициары), AML (источник денег), **санкционный скрининг ЕС** и
  PEP, **EU FDI Screening** (контроль иностранных инвестиций — с дек. 2025 новый регламент:
  проверяют обход санкций, непрозрачную структуру владения, бенефициара).
- **Данные (MCP):** OpenSanctions / санкционные и PEP-списки (UN, OFAC, EU, UK), реестры бенефициаров.
- **Выход:** отчёт «pass / enhanced due diligence / stop» — обязательный шлюз перед сделкой.

### 7. Agent «Management de transition» — транзитный менеджмент
- **Задача:** подобрать interim-управляющего под предприятие на переходный период.
- **Данные (MCP):** база interim-менеджеров (Airtable), профиль предприятия.
- **Выход:** 2–3 кандидата-управляющих + план ввода нового собственника в дело.

+ **Оркестратор (n8n):** запускает конвейер, ведёт статусы, уведомляет команду в Slack,
ставит встречи в Google Calendar. **Человек одобряет каждый ключевой шаг.**

## 🛠️ Стек и доступы (для бенчмарка, Часть 3)

| Слой | Инструмент | Зачем |
|---|---|---|
| Интерфейс / CRM-дашборд | **Base44** (или Lovable/Bubble) | пайплайн сделок, карточки, статусы |
| Оркестрация / автоматизация | **n8n** | связать агентов в конвейер |
| Движок рассуждений/генерации | **Claude (Sonnet/Opus)** | многоязычность (RU/AR/FR/EN), анализ документов |
| Данные компаний FR | **Pappers, Infogreffe, BODACC, INSEE SIRENE** | руководители, возраст, финансы, процедуры |
| Данные ЕС | **Orbis / Bureau van Dijk**, нац. реестры, Eurostat | пан-европейский охват |
| CRM покупателей | **HubSpot / Airtable** | профили и пайплайн |
| Почта / outreach | **Gmail / Outlook, Mailchimp** | контакт со сторонами |
| Data room / документы | **Google Drive / Notion / VDR** | сделочные документы |
| Календарь | **Google Calendar** | встречи |
| Команда | **Slack** | коллаборация, уведомления |
| Веб-разведка | **WebSearch / WebFetch** | сигналы, пресса, веолле |
| Сорсинг контактов | **LinkedIn Sales Navigator** | покупатели/продавцы (с оговоркой ToS) |
| Комплаенс | **OpenSanctions / sanctions & PEP API** | KYC/AML/санкции |

> 💡 **Аргумент для жюри (урок про MCP):** всё подключено через **MCP-коннекторы**, а не
> хардкодом. Значит — **портируемость и отсутствие vendor lock-in**: LLM или источник
> данных можно заменить, не переписывая систему. Это стратегическое преимущество и
> снижение регуляторного риска (можно держать данные в ЕС).

## ⚖️ Встроенные принципы (governance, для Части 5)
- **Human-in-the-loop:** агенты готовят, человек решает и подписывает.
- **Конфиденциальность M&A:** тизеры анонимны (anonymisés), доступ по NDA, данные в ЕС.
- **RGPD:** система работает с персональными данными → явное правовое основание,
  минимизация, срок хранения, права субъектов.
- **KYC/AML/санкции:** агент 6 — обязательный шлюз; без «pass» сделка не идёт.
- **EU AI Act:** классифицировать риск, обеспечить прозрачность и надзор человека.

## 📎 Что реально нужно подключить (для прототипа/пилота)
Чтобы собрать рабочий прототип и, позже, пилот — понадобятся доступы (перечень для
дорожной карты; на этапе Capstone показываем концепт/демо, полные доступы — на пилоте):
- Аккаунт **Base44** (интерфейс) и **n8n** (оркестрация).
- **Claude API** ключ (движок).
- **Pappers API** ключ (франц. данные компаний) — есть бесплатный тариф для демо.
- **Airtable/HubSpot** (CRM) — бесплатный тариф.
- **OpenSanctions** (санкции/PEP) — есть открытые данные.
- Позже (масштаб): **Orbis/Bureau van Dijk** (платно), профессиональный **VDR**.
