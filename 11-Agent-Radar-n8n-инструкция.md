# 🛰️ Agent Radar — сборка в n8n с ключом Pappers (инструкция)

Готовый workflow: **`prototype/radar-pappers-n8n.json`** — импортируешь одним файлом.
Агент запрашивает у API Pappers рентабельные компании со стареющим руководителем и
считает **«Score de succession» (0–100)**.

---

## Шаг 1 — Запустить n8n (выбери один способ)

- **Проще всего (локально, бесплатно):** в Терминале выполни
  ```
  npx n8n
  ```
  Откроется `http://localhost:5678` в браузере. *(Нужен Node.js — если нет, поставь с nodejs.org.)*
- **Или облако:** зарегистрируйся на **n8n.io** → Cloud (есть бесплатный триал).
- **Или n8n Desktop** — приложение для Mac.

## Шаг 2 — Получить ключ API Pappers

1. Зайди на **pappers.fr** → раздел **API** → создай аккаунт.
2. Получи **API key** (есть бесплатный тариф с квотой токенов для теста).
3. Скопируй ключ.

## Шаг 3 — Импортировать workflow

В n8n: **⋯ (меню) → Import from File** → выбери
`radar-pappers-n8n.json`. Появятся 4 узла: заметка, «Lancer Radar», «Pappers · Recherche»,
«Score de succession».

## Шаг 4 — Вставить ключ (credential)

1. Слева: **Credentials → New → «Header Auth»**.
2. Заполни:
   - **Name (в поле заголовка):** `api-key`
   - **Value:** `ТВОЙ_КЛЮЧ_PAPPERS`
3. Сохрани.
4. Открой узел **«Pappers · Recherche»** → в поле Credential выбери только что созданный
   `api-key`. *(Если узел просит выбрать credential после импорта — это нормально.)*

## Шаг 5 — Настроить фильтры (по желанию)

В узле **«Pappers · Recherche»** → *Query Parameters* уже стоят:
| Параметр | Значение | Смысл |
|---|---|---|
| `chiffre_affaires_min` | 1000000 | оборот от 1 M€ |
| `resultat_min` | 50000 | прибыль > 0 → **рентабельна** |
| `age_dirigeant_min` | 60 | руководитель у пенсии |
| `entreprise_cessee` | false | только действующие |
| `par_page` | 20 | сколько выдать |

Можно добавить (кнопкой *Add Parameter*):
- `code_naf` — отрасль (например `25.62B`);
- `departement` — департамент (например `69` — Рона);
- `code_postal`, `region`.

## Шаг 6 — Запустить

Нажми **Execute Workflow**. В узле «Score de succession» увидишь список компаний,
отсортированный по убыванию score:

```
score_succession · nom · siren · dirigeant_age · chiffre_affaires · resultat · lien_pappers
```

---

## 🧮 Как считается Score de succession
- Возраст руководителя: 70+ → +50 · 65–69 → +42 · 60–64 → +32 · 55–59 → +20
- Прибыль положительная → +20
- Оборот ≥ 2 M€ → +12 · ≥ 1 M€ → +8
- Единственный руководитель и возраст 60+ (нет очевидного преемника) → +10
- Максимум 100.

## ⚠️ Если ошибка
- **401 / 403** → неверный ключ или не выбран credential (Шаг 4).
- **Пусто** → ослабь фильтры (снизь `chiffre_affaires_min`, `age_dirigeant_min`).
- **Мало полей финансов** → в поиске Pappers не всегда есть CA/résultat в каждом результате;
  фильтры уже гарантируют рентабельность. Для полных финансов позже добавим узел-обогащение
  (`GET /v2/entreprise?siren=…`).
- Помни про **квоту токенов** Pappers — каждый запрос её тратит.
